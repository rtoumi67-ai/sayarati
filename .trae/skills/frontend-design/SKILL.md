# Frontend Design

Create distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to craft, layout, motion, and visual identity.

Use this skill when the user asks to build or beautify:
- Web pages
- Landing pages
- Dashboards
- React components
- HTML/CSS layouts
- Posters or promotional UI artifacts
- App interfaces
- Existing frontend sections that need a design upgrade

## Design Thinking

Before coding, understand the context and commit to a bold aesthetic direction.

### Purpose
- Identify what the interface solves
- Understand who will use it
- Clarify the key action or emotional outcome

### Tone
Pick a clear and memorable design direction. Examples:
- Brutally minimal
- Maximalist chaos
- Retro-futuristic
- Organic / natural
- Luxury / refined
- Playful / toy-like
- Editorial / magazine
- Brutalist / raw
- Art deco / geometric
- Soft / pastel
- Industrial / utilitarian

Do not stay vague. Commit to one direction and execute it precisely.

### Constraints
- Respect framework and project constraints
- Keep performance in mind
- Preserve accessibility and usability
- Match implementation complexity to the visual ambition

### Differentiation
Define one unforgettable element:
- A signature layout move
- A striking motion sequence
- A memorable typography system
- A unique composition or atmosphere

## Core Rule

The design must feel intentional, cohesive, and unmistakably crafted. Bold maximalism and refined minimalism both work, but only when executed with discipline.

## Frontend Aesthetics Guidelines

### Typography
- Choose fonts with character and intention
- Avoid generic defaults like Arial, Roboto, Inter, and bland system stacks unless explicitly required
- Pair a strong display font with a refined body font
- Use hierarchy, spacing, and rhythm deliberately

### Color And Theme
- Build around a strong, coherent palette
- Use CSS variables for consistency
- Prefer dominant color systems with precise accents over timid neutral-heavy palettes
- Avoid cliché purple-gradient-on-white looks unless the brief explicitly calls for them

### Motion
- Use motion to create impact, not noise
- Prefer CSS-first motion for simple interfaces
- Use Motion for React when meaningful
- Focus on key moments:
  - orchestrated page reveals
  - staggered entrances
  - hover transformations
  - scroll-triggered emphasis

### Spatial Composition
- Break predictable layout patterns
- Use asymmetry, overlap, negative space, density, contrast, and rhythm intentionally
- Let the composition carry the concept, not just the content

### Backgrounds And Visual Detail
- Add atmosphere and depth
- Use gradient meshes, noise, geometric textures, layered transparencies, dramatic shadows, custom borders, and visual systems that fit the chosen aesthetic
- Avoid default flat backgrounds when the concept needs more presence

## Anti-Generic Rules

Never fall into generic AI aesthetics:
- No cookie-cutter SaaS layout by default
- No predictable hero/cards/testimonials stack unless redesigned with a strong concept
- No overused type choices and visual shortcuts
- No safe-but-forgettable color decisions
- No bland component libraries pasted without refinement

Every design should feel specifically made for the user's context.

## Implementation Standard

The output must be:
- Real working code
- Production-grade
- Visually striking
- Consistent with a clear art direction
- Refined in spacing, interaction, and detail

## Complexity Matching

Match code complexity to the creative ambition:
- Maximalist interfaces should include layered effects, richer composition, and orchestrated motion
- Minimalist interfaces should show restraint, precision, and exceptional spacing discipline

Elegance comes from fit, not excess.

## Output Expectations

When using this skill:
1. Identify the audience, goal, and technical context
2. State the chosen visual direction clearly
3. Implement the UI in working code
4. Make the result memorable and polished
5. Avoid repeating aesthetics from previous generations

## Final Reminder

Think like a real frontend art director and engineer at the same time. The result should feel designed, not auto-generated.
